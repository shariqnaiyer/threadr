Fork map

Main line is the conversation a family started as. Each fork hangs under the session it was taken from, labelled with how many messages it inherited and when it split.

Lineage is reconstructed by threadr, not recorded: a transcript holds no pointer to its parent. Two sessions are related when they hold message ids in common, and the parent is the line whose own messages started first. A compacted session had its transcript rewritten, which can make an inherited count slightly low.

Click a session id to copy the command that resumes it.
